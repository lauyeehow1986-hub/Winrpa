quickstart.R 
library(winrpa)

# Desktop UIA + Win32 Window Lifecycle
rpa_launch("notepad.exe")
win <- rpa_wait_for(
  function() tryCatch(rpa_window(class_name = "Notepad"), error = function(e) NULL),
  timeout = 5, label = "Notepad"
) |> rpa_window_focus()

rpa_find(win, control_type = "Document", max_depth = 4L) |>
  rpa_type("Hello from winrpa! (Unicode: café 日本語)\n", mode = "unicode")

# Headless Edge/Chrome CDP (CSS, XPath & Network-Idle)
sess <- rpa_web_launch(headless = TRUE)
rpa_web_goto(sess, "https://example.org", wait = "load")
rpa_web_wait_network_idle(sess, idle_ms = 300L)
rpa_web_screenshot(sess, "page.png")
rpa_web_close(sess)

    Engineered for Reliability on Windows Desktops & CRAN

    Expand Diagram

    Dedicated Worker Isolation

    src/mta_worker.cpp

    Click diagram to zoom. COM interfaces run on an MTA thread; OS hotkeys & hooks run on a dedicated GetMessageW() pump.

    MTA vs STA Thread Isolation

    RGui and RStudio initialize COM on the main thread as Single-Threaded Apartment (STA). Running CoInitializeEx(COINIT_MULTITHREADED) on the main thread fails with RPC_E_CHANGED_MODE. winrpa spins up an isolated C++17 worker thread that owns IUIAutomation cleanly.

    Zero-Hang Exit & Reload Safety

    Windows R exits via ExitProcess() without calling .onUnload(), where joining C++ threads inside DllMain(DLL_PROCESS_DETACH) deadlocks on the OS loader lock. winrpa registers reg.finalizer(..., onexit = TRUE) to stop workers early and uses a fail-safe signal + detach() in destructors, while keeping shutdown() recoverable across pkgload::unload().

    RichEditD2DPT & Surrogate-Pair Precision

    Modern Windows 11 XAML/RichEdit controls drop rapid back-to-back VK_PACKET keystrokes. rpa_type() applies a 50ms focus settle, groups UTF-16 high/low surrogate pairs into atomic 4-event batches, enforces a >=2ms inter-key yield, and drains 20ms at completion.

    Cross-Platform Stub Portability

    All Windows API headers sit behind #ifdef _WIN32. On Linux and macOS, the package compiles cleanly with pure mathematical coordinate helpers intact and clear diagnostic stubs on Windows-only entry points.
